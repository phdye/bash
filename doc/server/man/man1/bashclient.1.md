# BASHCLIENT(1) -- command-line client for bash-server

# SYNOPSIS

    bashclient -s PATH -a TOKEN [-e COMMAND | -f SCRIPT | -i] [OPTIONS]

# DESCRIPTION

**bashclient** is a standalone command-line client that connects to a running
**bash-server**(1) instance over a Unix domain socket.  It authenticates using a
shared token, then executes commands in one of three modes: single-command
evaluation, script file execution, or interactive REPL.

The client communicates using the v1 (line-oriented text) protocol.  Each
command is sent as an `EVAL` request; the server responds with zero or more
`STDOUT` and `STDERR` lines carrying base64-encoded output, followed by an
`EXIT` line with the command's exit status.

If no mode flag (**-e**, **-f**, **-i**) is given and standard input is a
terminal, **bashclient** defaults to interactive mode.

**bashclient** is a self-contained executable that links only against
**cygwin1.dll** -- it does not depend on **cygbash-5.1.dll** or any Bash
libraries.

# OPTIONS

**-s**, **--socket** *PATH*
:   Path to the **bash-server** Unix domain socket.  Required.

**-a**, **--auth** *TOKEN*
:   Authentication token.  Required.  This is the hex-encoded 256-bit token
    generated by **bash-server** at startup and stored in
    *\<socket-path\>*.token.

**-e**, **--eval** *COMMAND*
:   Evaluate *COMMAND* in the server's Bash environment, print its output, and
    exit.  The client's exit status is the command's exit status.

**-f**, **--file** *SCRIPT*
:   Read *SCRIPT* line by line and evaluate each non-empty, non-comment line
    as a separate command.  Lines beginning with `#` are skipped.  The client's
    exit status is the exit status of the last command executed.

**-i**, **--interactive**
:   Enter interactive mode.  Presents a `bashclient>` prompt and reads
    commands from standard input.  Type `exit` or `quit` (or press Ctrl-D)
    to disconnect.

**-v**, **--verbose**
:   Print diagnostic messages, including unexpected server responses.

**-h**, **--help**
:   Print a usage summary and exit.

**-V**, **--version**
:   Print version information and exit.

# PROTOCOL

**bashclient** uses the v1 text protocol exclusively.  The command exchange
sequence is:

    Client:  AUTH <token>
    Server:  OK

    Client:  EVAL <command>
    Server:  STDOUT <base64-data>    (zero or more)
    Server:  STDERR <base64-data>    (zero or more)
    Server:  EXIT <code>

    Client:  PING
    Server:  PONG

    Client:  QUIT
    Server:  BYE

All messages are LF-terminated.  Carriage returns in received data are
stripped.  Output payloads (STDOUT, STDERR) are base64-encoded to preserve
binary data and newlines.

Error responses take the form `ERR <message>`.

# ENVIRONMENT

**BASH_SERVER_SOCKET**
:   Can be used by wrapper scripts to supply the socket path.  Note that
    **bashclient** itself currently requires the explicit **--socket** flag.

**BASH_SERVER_TOKEN**
:   Can be used by wrapper scripts to supply the authentication token.  Note
    that **bashclient** itself currently requires the explicit **--auth** flag.

# FILES

*\<socket-path\>*.token
:   Token file written by **bash-server**(1).  Wrapper scripts typically read
    this file and pass its contents via **--auth**.

# EXIT STATUS

| Code | Meaning                                            |
|------|----------------------------------------------------|
| 0    | Command (or last command in script/interactive) succeeded |
| 1    | Connection, authentication, or argument error       |
| 1-255| Exit status of the evaluated command (eval/script mode) |
| 127  | Communication failure or server error during execution |

# EXAMPLES

Evaluate a single command:

    bashclient -s /tmp/bash-server-1000/sock \
               -a "$(cat /tmp/bash-server-1000/sock.token)" \
               -e 'echo hello world'

Run a script file:

    bashclient -s /tmp/bash-server-1000/sock \
               -a "$(cat /tmp/bash-server-1000/sock.token)" \
               -f setup.sh

Interactive session:

    bashclient -s /tmp/bash-server-1000/sock \
               -a "$(cat /tmp/bash-server-1000/sock.token)" \
               -i

Using a shell wrapper for convenience:

    #!/bin/sh
    SOCK=/tmp/bash-server-$(id -u)/sock
    TOKEN=$(cat "${SOCK}.token")
    exec bashclient -s "$SOCK" -a "$TOKEN" "$@"
